# ISSCC 2027 Code-a-Chip — Open-Source CMOS PTAT Temperature Sensor

This repository is the consolidated home for the ISSCC 2027 Code-a-Chip PTAT temperature-sensor project.

## Project

**Open-source CMOS PTAT temperature sensor with digital calibration**, targeting reproducible analytical and SKY130 transistor-level evidence.

The maintained project is under:

`ISSCC27/submitted_notebooks/ptat_temp_sensor/`

## Current evidence status

- Analytical PTAT model: present
- Digital one-point / two-point calibration model: present
- Synthetic variation work: synthetic only; not PDK mismatch evidence
- Real SKY130 ngspice characterization: **retained CI run 221 evidence**
- SKY130 corners: **TT / FF / SS**
- Real PMOS-mirror characterization: **retained CI run 221 evidence**
- Silicon measurement: not available
- Statistical PDK mismatch Monte-Carlo: not claimed
- Layout DRC/LVS: not claimed as PASS

## Evidence-integrity gate

From `ISSCC27/submitted_notebooks/ptat_temp_sensor/` run:

```bash
python evidence_audit.py
```

The audit recomputes the promoted SKY130 metrics directly from retained CSVs and verifies them against the manifest and design seed. GitHub Actions runs the same check on pull requests and pushes.

## Evidence rule

No PDK, layout, DRC/LVS, statistical mismatch, or silicon result is promoted unless the corresponding evidence is actually retained and internally consistent.

# ISSCC 2027 Code-a-Chip — Open-Source CMOS PTAT Temperature Sensor

This repository is the consolidated v13 home for the competition-grade PTAT temperature-sensor project.

## Project

**Open-source CMOS PTAT temperature sensor with digital calibration**, targeting reproducible analytical, SPICE, and SKY130 evidence.

The main project is under:

`ISSCC27/submitted_notebooks/ptat_temp_sensor/`

# Open-Source CMOS PTAT Temperature Sensor with Digital Calibration

**ISSCC 2027 Code-a-Chip** — consolidated repository.

## Objective

A transparent, reproducible CMOS PTAT temperature-sensor study based on

`ΔVGS ≈ n·kT/q·ln(N)`

with digital one-point and two-point calibration, analytical/readout co-design, SKY130 transistor-level characterization, and explicit evidence provenance.

## Evidence classes

1. **Analytical** — first-principles Python model.
2. **Synthetic** — explicitly assumed Monte-Carlo variation; never presented as PDK/silicon.
3. **Real PDK** — generated by ngspice against SKY130/open_pdks and retained as raw CSV evidence with a machine-readable provenance manifest.

### Power evidence boundary

The ideal-bias result is the power of the two forced-current sensing branches. The mirror result includes the characterized PMOS bias network. These are **testbench/core figures**, not a claim for complete sensor/ADC system power.

## Evidence integrity

Run:

```bash
python evidence_audit.py
```

or:

```bash
make evidence-audit
```

The audit fails closed if:

- the canonical `design_requirements.json` hash no longer matches the retained run-221 manifest;
- the TT/FF/SS temperature grid changes;
- any retained CSV is missing, malformed, or non-finite;
- recomputed slope, ΔVGS@25°C, effective slope factor, nonlinearity, power, headroom, or mirror mismatch differs from the manifest;
- the retained headroom or mirror-mismatch engineering target is violated.

GitHub Actions runs the same audit on pull requests and pushes.

## Important limitations

- The real PDK evidence is transistor-level simulation, not silicon measurement.
- The mirror sweep is deterministic corner/temperature characterization, not statistical mismatch Monte Carlo.
- Layout, DRC, and LVS are not claimed as completed PASS.
- The current minimal repository does not contain the full historical notebook/Xschem/physical-verification harness from earlier packaged baselines; historical claims are not promoted as current rerunnable evidence unless their artifacts are retained here.
